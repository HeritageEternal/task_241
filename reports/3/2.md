# Структура каталогов

## 1. Структура каталогов в Linux и содержимое корня `/`

В Linux используется единая древовидная иерархия каталогов (стандарт **FHS - Filesystem Hierarchy Standard**), где всё растёт из одного корня `/` - без букв дисков, как в Windows. (лакшери)

Использованная команда:

```bash
ls -la /
```

Полученный результат:

## 2–4. Домашние каталоги и конфиги

- Домашние каталоги обычных юзеров хранятся в **`/home`** (например, `/home/darkextra`).
- Домашний каталог суперпользователя `root` лежит отдельно - в **`/root`**.
- Основные системные конфиги лежат в **`/etc`**.

## 5. Назначение основных каталогов

- `/bin` - базовые пользовательские бинарники (в современных дистрибутивах, включая Arch Linux, обычно симлинк на `/usr/bin`).
- `/sbin` - системные/админские бинарники (в Arch Linux - симлинк на `/usr/bin`).
- `/usr/bin` - основное хранилище исполняемых файлов программ и утилит.
- `/usr/sbin` - системные утилиты для администрирования (в Arch также объединены с `/usr/bin`).
- `/etc` - системные конфигурационные файлы и скрипты настройки служб.
- `/var` - изменяемые данные: логи (`/var/log`), кэши, очереди, базы данных.
- `/tmp` - временные файлы программ и юзеров (обычно в `tmpfs`, очищается при перезагрузке).
- `/home` - домашние каталоги обычных юзеров.
- `/root` - домашний каталог суперпользователя `root`.
- `/proc` - виртуальная ФС `procfs` с инфой о процессах и ядре.
- `/sys` - виртуальная ФС `sysfs` с деревом устройств, драйверов и параметров ядра.

## 6. Проверка `/bin` и `/sbin` в системе

Использованная команда:

```bash
ls -ld /bin /sbin
```

Полученный результат:

```text
lrwxrwxrwx 1 root root 7 окт 12  2025 /bin -> usr/bin
lrwxrwxrwx 1 root root 7 окт 12  2025 /sbin -> usr/bin
```

В Arch Linux оба пути - это **символические ссылки** на `usr/bin` (схема merged-usr).

## 7. Поиск физического расположения исполняемого файла команды

В качестве примера проверим команду `findmnt`, которой пользовались в прошлой задаче.

Использованная команда:

```bash
command -v findmnt && readlink -f "$(command -v findmnt)" && ls -l "$(command -v findmnt)"
```

Полученный результат:

```text
/usr/bin/findmnt
/usr/bin/findmnt
-rwxr-xr-x 1 root root 73400 сен 21 15:54 /usr/bin/findmnt
```

Исполняемый файл физически находится по пути `/usr/bin/findmnt`.

## Разница между обычным каталогом, симлинком и виртуальной ФС

- **Обычный каталог** - реальный объект на дисковой ФС, который содержит список файлов и подкаталогов.
- **Символическая ссылка (симлинк)** - специальный файл-указатель, который просто ссылается на другой путь (как `/bin -> usr/bin`); сама по себе файлы не хранит.
- **Виртуальная файловая система** (`/proc`, `/sys`) - точка монтирования интерфейса ядра; содержимое внутри неё не лежит на диске, а формируется ядром на лету.
