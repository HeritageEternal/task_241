# Скриптуем по полной

## 1. Что такое shebang

**Shebang** (`#!`) - это самая первая строка в текстовом скрипте, которая говорит ядру Linux, каким интерпретатором этот файл нужно запускать. Например, `#!/usr/bin/env bash` ищет `bash` в `$PATH` и передаёт ему скрипт на выполнение. Если shebang не указать, система попытается выполнить файл через дефолтную оболочку (обычно `/bin/sh`), из-за чего bash-специфичные штуки вроде `pipefail` или `[[ ... ]]` могут просто отвалиться.

## 2. Обязательно ли исполняемому файлу иметь расширение `.sh`

**Нет, не обязательно.** В Linux тип исполняемого файла определяется не расширением в имени, а правами на выполнение (`+x`) и содержимым - либо бинарным заголовком (ELF), либо строкой shebang в начале скрипта. Расширение `.sh` ставят исключительно для удобства людей и редакторов кода (подсветка синтаксиса и понимание, что внутри shell-скрипт).

## 3. Скрипт автоматизации работы с файлами

Создан скрипт `/home/darkextra/file_ops.sh` с правами на выполнение:

```bash
chmod +x ~/file_ops.sh
ls -l ~/file_ops.sh
```

Полученный результат:

```text
-rwxr-xr-x 1 darkextra darkextra 2993 ноя 21 02:00 /home/darkextra/file_ops.sh
```

### Полный текст скрипта `/home/darkextra/file_ops.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

if [[ $# -lt 1 || -z "${1:-}" ]]; then
    echo "Ошибка: не указан рабочий каталог." >&2
    echo "Использование: $0 <рабочий_каталог>" >&2
    exit 1
fi

WORK_DIR="$1"
LOG_FILE="${WORK_DIR}/actions.log"

mkdir -p "${WORK_DIR}"

log() {
    local msg
    msg="[$(date '+%Y-%m-%d %H:%M:%S')] $1"
    echo "$msg" | tee -a "$LOG_FILE"
}

log "=== Запуск скрипта для каталога: ${WORK_DIR} ==="

# 1. Создание структуры каталогов
mkdir -p "${WORK_DIR}/docs" "${WORK_DIR}/backup" "${WORK_DIR}/archive"
log "Проверена/создана структура каталогов: docs, backup, archive"

# 2. Создание исходного файла (без перезаписи существующего)
NOTE_FILE="${WORK_DIR}/docs/notes.txt"
if [[ -e "$NOTE_FILE" ]]; then
    log "ПРЕДУПРЕЖДЕНИЕ: ${NOTE_FILE} уже существует - пропускаю создание, чтобы не затереть данные"
else
    cat > "$NOTE_FILE" <<'DATA'
Linux file operations lab
Line 2: grep target keyword
Line 3: end of file
DATA
    log "Создан файл: ${NOTE_FILE}"
fi

# 3. Копирование файла в backup (без перезаписи)
BACKUP_FILE="${WORK_DIR}/backup/notes_backup.txt"
if [[ -e "$BACKUP_FILE" ]]; then
    log "ПРЕДУПРЕЖДЕНИЕ: ${BACKUP_FILE} уже существует - пропускаю копирование"
else
    cp "$NOTE_FILE" "$BACKUP_FILE"
    log "Скопирован файл: ${NOTE_FILE} -> ${BACKUP_FILE}"
fi

# 4. Создание временного файла и его переименование (mv)
RENAMED_FILE="${WORK_DIR}/docs/report.txt"
if [[ -e "$RENAMED_FILE" ]]; then
    log "ПРЕДУПРЕЖДЕНИЕ: ${RENAMED_FILE} уже существует - пропускаю создание/переименование"
else
    TMP_FILE="${WORK_DIR}/docs/draft.tmp"
    echo "Временный черновик отчёта" > "$TMP_FILE"
    mv "$TMP_FILE" "$RENAMED_FILE"
    log "Создан и переименован файл: ${TMP_FILE} -> ${RENAMED_FILE}"
fi

# 5. Поиск файлов (find) и текста (grep)
FILE_COUNT=$(find "${WORK_DIR}/docs" -type f | wc -l)
log "Найдено файлов в ${WORK_DIR}/docs: ${FILE_COUNT}"

MATCHES=$(grep -c "keyword" "$NOTE_FILE" || true)
log "Совпадений 'keyword' в ${NOTE_FILE}: ${MATCHES}"

# 6. Архивация каталога docs (без перезаписи)
ARCHIVE_FILE="${WORK_DIR}/archive/docs.tar.gz"
if [[ -e "$ARCHIVE_FILE" ]]; then
    log "ПРЕДУПРЕЖДЕНИЕ: ${ARCHIVE_FILE} уже существует - пропускаю пересоздание архива"
else
    tar -czf "$ARCHIVE_FILE" -C "${WORK_DIR}" docs
    log "Создан архив: ${ARCHIVE_FILE}"
fi

log "=== Скрипт успешно завершён ==="
```

### Назначение параметров `set -euo pipefail`

- **`-e` (`errexit`)** - немедленно завершает скрипт, если любая команда вернула ненулевой код возврата (ошибку), чтобы скрипт не молотил дальше на сломанном состоянии.
- **`-u` (`nounset`)** - считает обращение к необъявленной переменной ошибкой и сразу останавливает выполнение (спасает от опечаток в именах переменных, особенно рядом с `rm` и путями).
- **`-o pipefail`** - меняет поведение пайпов (`cmd1 | cmd2`): по умолчанию код возврата пайпа берётся только от последней команды, а с `pipefail` весь пайп вернёт ошибку, если упала любая команда в цепочке.


Скрипт вывел понятную подсказку в `stderr` и завершился с ненулевым кодом возврата **`1`**.
