## 1 и 7. Скрипт сбора информации (независимо от текущего каталога)

Создан скрипт `/usr/local/bin/lab_sysinfo.sh`. Он сам определяет домашний каталог юзера, от которого запущен (`USER_HOME`), поэтому не зависит от текущего рабочего каталога (`WorkingDirectory`), проверяет существование каталога `lab_info` и файлов `1`, `2`, `3`, `4`, записывает в них дату, версию ядра, hostname и список файлов домашнего каталога, а в конце делает `sleep 5` (чтобы успеть поймать живой PID процесса).

Полный текст `/usr/local/bin/lab_sysinfo.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

USER_HOME="${HOME:-$(getent passwd "$(id -un)" | cut -d: -f6)}"
TARGET_DIR="${USER_HOME}/lab_info"

echo "Запуск lab_sysinfo.sh: user=$(id -un), PID=$$, HOME=${USER_HOME}"

if [[ ! -d "$TARGET_DIR" ]]; then
    mkdir -p "$TARGET_DIR"
    echo "Создан каталог: ${TARGET_DIR}"
else
    echo "Каталог уже существует: ${TARGET_DIR}"
fi

write_file() {
    local filepath="$1"
    local content="$2"
    if [[ -f "$filepath" ]]; then
        echo "Файл ${filepath} уже существует - обновляю содержимое"
    else
        echo "Создаю новый файл: ${filepath}"
    fi
    printf '%s\n' "$content" > "$filepath"
}

write_file "${TARGET_DIR}/1" "$(date)"
write_file "${TARGET_DIR}/2" "$(uname -r)"
write_file "${TARGET_DIR}/3" "$(uname -n)"
write_file "${TARGET_DIR}/4" "$(ls -la "${USER_HOME}")"

sleep 5
echo "Скрипт lab_sysinfo.sh успешно завершён"
```

Права на скрипт (`sudo chmod 755 /usr/local/bin/lab_sysinfo.sh`):

```text
-rwxr-xr-x 1 root root 993 ноя 21 12:14 /usr/local/bin/lab_sysinfo.sh
```

## 2–4. Создание service и timer, запуск по умолчанию от `root`

По умолчанию системные systemd units (из `/etc/systemd/system` и `/usr/lib/systemd/system`), если в них не указан параметр `User=`, выполняются от суперпользователя **`root`**.

### Исходный `/etc/systemd/system/lab-sysinfo.service`

```ini
[Unit]
Description=Lab System Info Collector Service

[Service]
Type=oneshot
ExecStart=/usr/local/bin/lab_sysinfo.sh
```

### Таймер `/etc/systemd/system/lab-sysinfo.timer` (каждые 5 минут)

```ini
[Unit]
Description=Run Lab System Info Collector every 5 minutes

[Timer]
OnCalendar=*:0/5
Persistent=true
Unit=lab-sysinfo.service

[Install]
WantedBy=timers.target
```

### Применение конфигов, включение таймера и первый запуск

Использованные команды:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now lab-sysinfo.timer
sudo systemctl start lab-sysinfo.service
systemctl status lab-sysinfo.service --no-pager
systemctl list-timers lab-sysinfo.timer --no-pager
sudo ls -la /root/lab_info
```

## 5, 6 и 8. Отдельный юзер `labsvc`, обновление юнита и определение PID во время работы

Создан отдельный сервисный юзер `labsvc` с домашним каталогом `/home/labsvc` и оболочкой `/usr/bin/nologin`. В юнит добавлены `User=labsvc`, `Group=labsvc`, а также `WorkingDirectory=/tmp` - чтобы наглядно проверить, что скрипт всё равно работает в домашнем каталоге юзера (`/home/labsvc/lab_info`).

Итоговый `/etc/systemd/system/lab-sysinfo.service`:

```ini
[Unit]
Description=Lab System Info Collector Service

[Service]
Type=oneshot
User=labsvc
Group=labsvc
WorkingDirectory=/tmp
ExecStart=/usr/local/bin/lab_sysinfo.sh
```

Использованные команды:

```bash
sudo useradd -m -s /usr/bin/nologin labsvc
id labsvc
sudo systemctl daemon-reload
sudo systemctl start --no-block lab-sysinfo.service
sleep 1
systemctl status lab-sysinfo.service --no-pager
ps -f -u labsvc
```

## 10. Намеренная ошибка, диагностика `failed` и исправление

```bash
sudo sed -i 's|lab_sysinfo.sh|lab_sysinfo_BROKEN.sh|' /etc/systemd/system/lab-sysinfo.service
sudo systemctl daemon-reload
sudo systemctl start lab-sysinfo.service || true
systemctl status lab-sysinfo.service --no-pager || true
journalctl -u lab-sysinfo.service -n 10 --no-pager
```
